# 3. Самая важная механика — развитие эфира

Вместо обычной маны можно сделать интересную систему.

Каждый ход игрок получает:

### Эфир

Используется для карт.

### Каналы

Определяют, сколько эфира приходит.

Например:

```text
Ход 1: 1 канал → 1 эфир
Ход 2: 2 канала → 2 эфира
Ход 3: 3 канала → 3 эфира
```

Но игрок может вмешиваться:

* уничтожить каналы врага;
* перегрузить собственные;
* украсть эфир;
* сохранить энергию;
* превратить здоровье в эфир.

Это сохраняет одну из самых интересных идей оригинальной системы: **ресурс сам становится частью тактики боя**. ([KV.by][2])

# 4. Герой — не просто портрет

Предлагаю сделать **героя полноценной частью билда**.

У каждого героя:

### Пассивная специализация

Например:

**Пиромант**

> Каждый третий огненный спелл получает +50% силы.

**Биомант**

> Первое призванное существо каждого хода получает мутацию.

**Архитектор**

> Создания-механизмы оставляют после смерти детали.

**Проводник Пустоты**

> Может играть карты из изгнания.

# 5. Система колоды

Чтобы избежать проблемы современных карточных игр, где игрок просто копирует метовую колоду:

### Колода = 20–30 карт

Но карты имеют **связи**.

Например:

### Карта

**Пепельный волк**

```text
Стоимость: 2
Атака: 3
Здоровье: 2

Когда получает урон:
получает +1 атаки.
```

Идеально работает с:

**Кровавый огонь**

> Нанеси 1 урон всем своим существам.
> Они получают Ярость.

Так появляются комбо, а не просто набор «самых сильных карт».

# 6. Самое современное улучшение — эволюция карт

Вот здесь можно реально сделать игру уникальной.

После важных боёв карта может **изменяться**.

Например:

### Обычная карта

**Лесной страж**
`2/4`

⬇️ после нескольких побед

Выбор:

### Вариант A

**Древний страж**

* больше здоровья;
* защита мага.

### Вариант B

**Хищный страж**

* меньше здоровья;
* атакует дважды.

### Вариант C

**Заражённый страж**

* получает способности Пустоты.

То есть **у каждого игрока постепенно формируется уникальная версия колоды**.

## Новая ключевая механика

**Маги не бьют друг друга напрямую как основной способ боя.**

Мы:

1. 🃏 разыгрываем карту существа;
2. 👹 существо появляется **на поле боя**;
3. ⚔️ существа сражаются с существами противника;
4. 💥 если на пути нет защитника — существо атакует мага;
5. 🪄 заклинания помогают существам, наносят урон или меняют поле.

То есть поле должно стать примерно таким:

```text
┌─────────────────────────────────────┐
│           ВРАЖЕСКИЙ МАГ ❤️ 28       │
│                                     │
│   [ Голем 5/8 ] [ Волк 3/2 ]        │
│─────────────────────────────────────│
│                                     │
│   [ Дух 2/4 ]  [ Энт 4/7 ]          │
│                                     │
│            НАШ МАГ ❤️ 30            │
└─────────────────────────────────────┘
```

### Например

**Дух рощи**

```text
Стоимость: 2 эфир
Атака: 3
Здоровье: 4

Способность:
В конце вашего хода восстанавливает
1 здоровье соседнему существу.
```

А не «наносит 8 урона автоматически».

### 1. Не «моё существо выбирает врага», а фаза атаки

Игрок выбирает любых готовых существ:


**«Начать атаку»**

## 2. Самое важное — система блоков

Например:

### До атаки

```text
ИГРОК

🐺 Волк 4/2
🌳 Древень 5/8


ВРАГ

👹 Голем 4/7
🐀 Зверь 2/3
```

Игрок атакует обоими.

ИИ выбирает блоки:

```text
🐺 Волк  ─── 🐀 Зверь
🌳 Древень ─ 👹 Голем
```

Но главное: **несколько существ могут блокировать одного атакующего**.

```text
            🐀
             ╲
🌳 Древень ⚔️ 👹
             ╱
            🕷️
```

Именно это делает боёвку тактической.

Защитник выбирает, кто кого блокирует, причём одного атакующего могут блокировать несколько существ. ([Igromania.ru][1])

# 3. Последовательный бой, а не одновременный обмен

Это особенно важно.

В руководстве описана такая логика:

### Атакующий бьёт первым

```text
Волк 5 атаки
        ↓
Голем 3 HP
```

Голем погибает.

### Тогда следующий защитник принимает удар

Если атакующий ещё способен продолжать:

```text
Волк → следующий блокер
```

И только после этого **выжившие защитники наносят ответный удар**. ([Igromania.ru][1])

Это намного интереснее нашего текущего:

> `attacker.hp -= defender.atk`
> `defender.hp -= attacker.atk`

### Я предлагаю реализовать именно эту систему.

# Новая структура боя

## Фаза 1 — Начало хода

```text
+1 карта
+ эфир
+ восстановление существ
```

Важный момент: согласно руководству, **неизрасходованный эфир не накапливается**, а существа поднимаются в начале хода владельца. ([Igromania.ru][1])

Для нашего прототипа я бы сделал:

```text
Эфирные каналы: 3

Начало хода:
Эфир = 3
```

А не постепенное накопление до 8.

Это будет намного ближе к «Демиургам».

---

## Фаза 2 — Разыгрывание карт

Игрок:

* вызывает существ;
* применяет колдовство;
* накладывает чары;
* использует способности.

Типы карт стоит разделить так:

### 👹 Вызов

```text
Молодой древень
Стоимость: 4
5 / 8
```

### ✨ Чары

Остаются на поле.

Например:

```text
Каменная кожа

Существо получает:
-2 физического урона.
```

### 💥 Колдовство

Одноразовый эффект.

```text
Огненный залп

Нанести 4 урона существу.
```

Это соответствует трём типам заклинаний из руководства. ([Igromania.ru][1])

# 4. Фаза объявления атаки

Вместо текущей кнопки:

> ⚔ Атаковать существом X цель Y

Сделаем:

```text
┌─────────────────────────┐
│ Выберите атакующих      │
│                         │
│ ☑ Волк       4/2        │
│ ☑ Древень    5/8        │
│ ☐ Целитель   1/5 💤     │
│                         │
│ [ ⚔ НАЧАТЬ АТАКУ ]      │
└─────────────────────────┘
```

Игрок сам выбирает **любое количество готовых существ**.

# 5. Фаза блокировки ИИ

После нажатия:

## ⚔️ АТАКА!

Поле меняется:

```text
════════════════════════════

       🐺 4/2  → АТАКУЕТ

       🌳 5/8  → АТАКУЕТ


════════════════════════════

ИИ думает...

👹 Голем 4/7
        ↓
     блокирует
        ↓
🌳 Древень
```

ИИ выбирает блоки по приоритетам:

### Приоритет ИИ

1. Убить опасное существо.
2. Спасти героя от смертельного урона.
3. Выгодно обменять слабое существо на сильное.
4. Не жертвовать сильным существом без причины.
5. При необходимости использовать несколько блокеров.

# 6. Прорыв к магу

Если существо никто не блокирует:

```text
🐺 Волк 4/2
     ↓↓↓
❤️ Вражеский маг
```

Он получает 4 урона.

Это ключевой элемент оригинальной системы. ([Igromania.ru][1])

# 7. Повреждения должны заживать после боя

Это **очень важное отличие**, которое сейчас у нас отсутствует.

В *Демиургах II* после завершения боя повреждения существ заживают, а погибшие отправляются в могильник. ([Igromania.ru][1])

То есть:

```text
До боя:

Древень
5 / 8
```

После боя:

```text
5 / 3
```

После завершения боевой фазы:

```text
5 / 8
```

Это полностью меняет баланс.

### Следовательно:

**HP существа — это не долгосрочный ресурс.**

Оно определяет:

> может ли существо пережить конкретную боевую фазу.

Это очень характерная механика «Демиургов».

# 8. Добавляем могильник

В текущем прототипе обязательно нужен:

```text
☠ Могильник игрока: 3
☠ Могильник врага: 2
```

Погибшие существа не исчезают полностью.

Позже появятся карты:

### ♻️ Реанимация

```text
Вернуть существо из могильника.
```

### ⚙️ Синтетическое восстановление

```text
Вернуть случайное существо из могильника
с +1/+1.
```

В руководстве прямо отмечается, что существа из могильника могут возвращаться определёнными заклинаниями. ([Igromania.ru][1])
